# MOMENTUNDIGITAL

Web corporativa de MOMENTUNDIGITAL desarrollada con Next.js. Incluye páginas de servicios, recursos editoriales, diagnóstico de proyecto, asistente guiado, SEO técnico y formulario de contacto mediante Resend.

## Desarrollo

```bash
npm install
npm run dev
```

La aplicación estará disponible en `http://localhost:3000`.

## Producción

```bash
npm run build
npm start
```

Copia `.env.example` como `.env.local` y completa las variables necesarias. Nunca publiques una clave real en Git.
